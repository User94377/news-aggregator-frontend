# News Aggregator UI — Клиентская часть агрегатора новостей

Клиентская часть семантического агрегатора новостей с поддержкой AI-кластеризации сюжетов, адаптивным дизайном и темной темой.

Приложение позволяет просматривать новостную ленту в двух режимах (классическая лента и сгруппированные AI-сюжеты), читать очищенный контент статей, управлять RSS-источниками и сохранять избранное.

## Ключевые возможности интерфейса

- Режимы отображения. Переключение между классической лентой и сгруппированными AI-сюжетами.
- Интерактивное чтение. Встроенное модальное окно для чтения очищенного контента статей без рекламы и лишних элементов.
- Фильтрация и поиск. Фильтрация по 11 категориям, поиск по заголовкам, фильтр «только позитивные новости».
- Личный кабинет и избранное. Сохранение статей в избранное, отображение статистики любимых рубрик пользователя.
- Управление RSS-источниками. Модальное окно добавления, удаления и включения/отключения RSS-источников в реальном времени.
- Темизация. Поддержка светлой и темной темы.

## Технологический стек

- Фреймворк: React, TypeScript, Vite
- Стилизация: Tailwind CSS, Tailwind Typography plugin
- HTTP-клиент: Axios
- Анимации: CSS Keyframe animations
