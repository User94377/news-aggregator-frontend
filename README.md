News Aggregator UI (React + TypeScript)

Клиентская часть агрегатора новостей с поддержкой AI-кластеризации сюжетов.

Стек технологий

Фреймворк: React, TypeScript, Vite
Стилизация: Tailwind CSS, Tailwind Typography plugin
HTTP-клиент: Axios
Анимации: CSS Keyframe animations
Функционал интерфейса

Режимы отображения: Переключение между классической лентой и сгруппированными AI-сюжетами.
AI Сводка: Отображение сгенерированного саммари от нейросети для объединенных сюжетов.
Интерактивное чтение: Встроенное модальное окно для чтения очищенного контента статей без рекламы.
Фильтрация и поиск: Фильтрация по 11 категориям, поиск по заголовкам, фильтр «только позитивные новости».
Личный кабинет и избранное: Сохранение статей в избранное, статистика любимых рубрик пользователя.
Управление RSS: Модальное окно добавления/удаления RSS-источников и управления их активностью.
